# Hygiene smells

These are code-level findings rather than architectural ones — they don't describe a structural pressure the way the other categories do, but they're recurring, evidence-detectable, and worth the same evidence-before-recommendation discipline. Keep them here rather than inflating them into structural smells they aren't.

| id | Smell | Description | Attributes in tension | Candidate movements | Common false positive |
|---|---|---|---|---|---|
| `unclear-naming` | Unclear naming | Generic names (`Manager`, `Helper`, `Service`, `Processor`, `Data`, `Info`, `Utils`), one name covering several concepts, or one concept under several names. | none — this is close to a pure `comprehensibility` win with little real tension, which is exactly why it's easy to over-recommend on taste alone | Rename to the concept actually hidden; align with product/domain language | A name that reads generically but is genuinely the only reasonable name for a genuinely generic thing |
| `dead-or-obsolete-code` | Dead or obsolete code | Unused members, permanently-set feature flags, unreachable deprecated paths, or compatibility code for unsupported versions. | none directly — removing it is close to a pure `comprehensibility`, `security` win, contingent entirely on the deletion being safe | Delete; remove the flag; drop the compatibility path | Code that looks unreferenced by local search but is reached through reflection, serialization, routing, or an external consumer |
| `duplicated-knowledge` | Duplicated knowledge | The same rule, validation, or configuration is implemented in more than one place, outside of the domain-modelling context covered by `domain.md`'s `multiple-representations-without-ownership`. | `consistency`, `modifiability` vs. locality of each copy | Extract the shared rule; single source of truth; generate one representation from the other | Two fragments that merely look similar (superficial textual duplication) without encoding the same rule, or two copies that have never actually needed to change together |
